# RTL433 radio history

The Pi's RTL-SDR continues decoding 433 MHz transmissions. RTL433 publishes
events to `rtl_433/rpi3b/events` on the cluster MQTT broker. A Telegraf service
in Kubernetes subscribes to that topic and stores decoded JSON fields in the
dedicated InfluxDB 2 `rtl433` bucket. The bucket retains 90 days. This leaves
Home Assistant's `homeassistant` history separate.

The reader and writer credentials are restricted to the `rtl433` bucket and
stored in SOPS-encrypted Kubernetes Secrets. Grafana has a separate read-only
datasource named **RTL433**. The provisioned **RTL433 Devices** dashboard shows
the unique IDs heard during the last 24 hours and recent readings with time,
model, ID, channel, field, and value.

## What “active” means

Most 433 MHz sensors are transmit-only. The dashboard can show that a device
was heard during a time window; silence does not prove that a device is offline.
The Pi also publishes discovery/availability topics, but the history pipeline
currently stores event messages only.

## Verify the pipeline

```bash
kubectl --kubeconfig .talos-local/kubeconfig -n rtl433 \
  get deployment,pod,configmap
kubectl --kubeconfig .talos-local/kubeconfig -n rtl433 \
  logs deployment/telegraf-rtl433 --tail=50
kubectl --kubeconfig .talos-local/kubeconfig -n influxdb \
  get helmrelease,pod,pvc
```

The Grafana dashboard is provisioned from a ConfigMap in the `observability`
namespace. Select **RTL433 Devices** from Grafana's dashboards. The datasource
health endpoint is `/api/datasources/uid/rtl433-influxdb/health`.

For direct Flux exploration:

```flux
from(bucket: "rtl433")
  |> range(start: -24h)
  |> filter(fn: (r) => r["_measurement"] == "rtl433")
  |> keep(columns: ["_time", "model", "id", "channel", "_field", "_value"])
  |> group()
  |> sort(columns: ["_time"], desc: true)
  |> limit(n: 100)
```

The root cluster Kustomization registers the `rtl433` child. It depends on
InfluxDB, Mosquitto, and observability. Its Kustomization decrypts its writer
Secret with the cluster SOPS key. The Grafana datasource Secret is reconciled
through the observability Kustomization.
