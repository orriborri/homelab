# Architecture decision records

Record decisions that shape the homelab's architecture, such as cluster
design, GitOps structure, networking, storage, secrets, and shared
controllers.

Use `template.md` and name records `NNNN-short-decision-title.md`,
starting with `0001`. Assign the next unused number.

Include the context, decision, alternatives, and consequences.
Link related GitHub issues and relevant configuration.

Use these statuses: Proposed, Accepted, Rejected, Deprecated, Superseded.
For a superseded decision, link the replacement ADR.

Preserve accepted decisions as history. Record a changed decision in a
new ADR and update the old record's status and replacement link.
